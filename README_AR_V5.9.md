# v5.9 — تخصيص كامل للبرنامج (Customization)

تخصيص واجهة فقط — لا تغيير في أي حساب أو منطق أعمال (المخزون، الإجمالي، FEFO، الآجل، PIN، الأمان كلها كما هي في v5.5–v5.8).

## ما تم تخصيصه شاشة شاشة
- **تسجيل الدخول:** اسم الصيدلية يظهر بخط كبير تحت عنوان البرنامج، وعنوان أكبر.
- **المظهر:** 3 ألوان تمييز (تركوازي افتراضي / أزرق / أخضر) + فاتح/داكن + 3 أحجام خط (عادي / كبير / كبير جداً)، تُحفظ في قاعدة البيانات وتُطبق فوراً وتبقى بعد إعادة التشغيل.
- **لوحة التحكم:** بطاقات أكبر وأرقام أوضح (24pt)، الأرقام بفواصل آلاف (1,234.50 ج.م)، بطاقة "صافي ربح اليوم" صارت هي الرقم الرئيسي (الربح بعد الخصم ناقص مصروفات اليوم — نفس حساب v5.7)، والتنبيهات (نقص مخزون + قرب انتهاء) صارت في الأعلى بعرض كامل قبل "الأكثر مبيعاً".
- **الكاشير:** باركود بخط أكبر، الإجمالي بخط 28pt، أزرار أكبر.
- **المخزون / العملاء / التقارير / الخزنة / التنبؤ:** صفوف الجداول أعلى (34px) وأوضح، وألوان الحالات كما هي (أحمر منتهي، برتقالي قريب الانتهاء، أخضر سليم).
- **الإيصال:** اسم الصيدلية في الأعلى، والإجمالي والمدفوع والباقي بخط عريض في المعاينة.
- **صفحة الموبايل:** أزرار أكبر (19px)، الإجمالي 28pt، عناوين أكبر — نفس الكلمات المختصرة (v5.2) ونفس سجل الفواتير والتعديل المرحلي (v5.5/v5.8).

## 🎨 التخصيص — غيّرها بنفسك من الإعدادات
الإعدادات → قسم "🎨 التخصيص": لون التمييز، حجم الخط، بطاقات لوحة التحكم الظاهرة (ألغِ تحديد أي بطاقة لإخفائها)، والتنبيهات في الأعلى أو لا. زر "✅ تطبيق التخصيص" يطبقها فوراً ويحفظها. كل اختيار له قيمة افتراضية آمنة، وإذا لم يوجد في قاعدة بيانات قديمة يعود للافتراضي تلقائياً.
