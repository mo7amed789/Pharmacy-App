# v6.23 — زر «📷 مسح» بجانب خانة باركود العلبة

## المشكلة
في نافذة «إضافة دواء جديد» كانت خانة **باركود العلبة (GTIN)** تُملأ يدوياً فقط،
والطلب كان زراً بجانبها يسمح بالمسح من جهاز الماسح أو من صفحة الموبايل.

## الحل — زر واحد، طريقتان للمسح
بجانب خانة باركود العلبة ظهر زر **«📷 مسح»**. يفتح نافذة «مسح باركود العلبة» فيها:

### ١) ماسح الباركود (USB)
أجهزة الماسح تعمل كلوحة مفاتيح: تكتب الأرقام ثم Enter. النافذة تفتح والمؤشر
جاهز في خانة المسح — امسح مباشرة فيُملأ باركود العلبة وتُغلق النافذة.
لا تعريفات ولا إعدادات.

### ٢) كاميرا الموبايل
زر **«📱 اطلب المسح من الموبايل»** يرسل طلب مسح عبر سيرفر الموبايل.
صفحة الموبايل تعرض خلال ثوانٍ تنبيهاً بارزاً:
**«🖥️ الكمبيوتر يطلب مسح باركود»** مع زر **«امسح الآن للكمبيوتر»** — يفتح
الكاميرا (نفس ماسح المبيعات)، وأول باركود يُقرأ يُرسل للكمبيوتر فوراً
وتُملأ خانة باركود العلبة تلقائياً وتُغلق النافذة.

- إن كان سيرفر الموبايل متوقفاً، تظهر رسالة توجهك لتشغيله من تبويب «📱 موبايل».
- الطلب له مهلة (3 دقائق) ويُلغى تلقائياً عند إغلاق النافذة، وزر «إلغاء»
  يلغيه فوراً. طلب جديد يستبدل القديم — لا تراكم.
- بعد امتلاء الخانة، Enter يحفظ الدواء كالمعتاد — وسلوك المسح القديم
  (الماسح مباشرة في الخانة) لم يتغير.

## تقنياً
- `mobile_server.py`: صندوق طلبات مسح في الذاكرة (طلب واحد نشط، مهلة
  180 ثانية، thread-safe) + مساران جديدان محميان بالـ PIN:
  `GET /api/scan-request` (هل يوجد طلب؟) و `POST /api/scan-result`
  (تسليم الكود — 409 لطلب منتهٍ أو رقم غير مطابق).
- `mobile.html`: استطلاع كل 3 ثوانٍ + تنبيه «الكمبيوتر يطلب مسح باركود»
  + تسليم الكود للكمبيوتر يتقدم على سلوك البحث المعتاد.
- `main.py`: زر «📷 مسح» بجانب خانة الباركود + نافذة المسح
  (`_barcode_scan_dialog`) بمساري USB والموبايل، وتستطلع نتيجة
  الموبايل كل ثانية.
- `sw.js`: تحديث الكاش إلى `pharmacy-mobile-v623` حتى تجلب الهواتف الصفحة الجديدة.
