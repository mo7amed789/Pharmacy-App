# v6.18 — تلميع الواجهة: أزرار بلغة واحدة + ألوان حالات موحّدة + رسائل منبثقة بشكل البرنامج

تحديث شكلي بالكامل — لا يغيّر أي سلوك أو اختصار أو ترتيب شاشات، فقط كيف تبدو الأزرار والحالات والرسائل.

## 1) الأزرار — هرمية واحدة مفهومة في كل الشاشات

كل زر في البرنامج صار له معنى من لونه:

| اللون | المعنى | أمثلة |
|---|---|---|
| تركوازي (الأكسنت) | الخطوة الرئيسية | دخول، اعتماد التعديلات، تشغيل السيرفر |
| أخضر | تأكيد وحفظ وإتمام | إتمام البيع، 💾 حفظ، حفظ فاتورة الشراء، استرجاع سطر |
| أحمر | إجراء تدميري | حذف السطر، إرجاع فاتورة، حذف سطر شراء |
| كهرماني | حذر | مسح الفاتورة |
| رمادي هادئ | كل الأزرار المحايدة | بحث، تحديث، عرض |

- كل زر ملوّن صار له حالتان واضحتان: **تفتيح عند مرور الماوس** و**تغميق عند الضغط** (قبلها كان الأكسنت فقط الذي يتجاوب، والباقي جامد).
- الأنماط الجديدة `Warning.TButton` و`Info.TButton` أُضيفت، و`Success.TButton` و`Danger.TButton` اكتسبا حالات المرور والضغط.

## 2) ألوان الحالات — لغة واحدة لكل شاشة

قاموس حالات موحّد في `ui_theme` (نجاح/تحذير/خطر/معلومة/باهت) تسحب منه كل الشاشات:

- **سيرفر الموبايل:** «🟢 يعمل» بالأخضر و«🔴 متوقف» بالأحمر (كانت رمادية دائماً).
- **هوت سبوت ويندوز:** يعمل=أخضر، متوقف=أحمر، غير معروف=كهرماني.
- **المزامنة السحابية:** مفعّلة=أخضر، بها خطأ=أحمر، غير مفعّلة=كهرماني.
- **بطاقات لوحة التحكم والتقارير والتنبؤ** تسحب ألوانها من اللوحة بدل ألوان الثيم الفاتح المنقوشة يدوياً (كانت تبدو باهتة في الوضع الداكن).
- وسوم جداول جديدة جاهزة: `paid`/`due`/`failed`/`synced` + وسم `held` (السطر المحذوف مؤقتاً) انتقل للثيم نفسه بدل لون منقوش في شاشتين.

## 3) الرسائل — صناديق بشكل البرنامج بدل شكل ويندوز الافتراضي

وحدة جديدة `ui_dialogs.py` تحل محل `messagebox` في كل البرنامج (180 موضع رسالة) بنفس النداءات تماماً:

- نافذة منبثقة مثيمة: شريط علوي بلون شدة الرسالة (ℹ️ معلومة زرقاء، ✅ نجاح أخضر، ⚠️ تنبيه كهرماني، ⛔ خطأ أحمر)، عنوان عريض، نص الرسالة داخل خلفية بلون الحالة، وزر «حسناً» بلون الشدة.
- «نعم / لا» في التأكيدات بنفس الشكل؛ **Escape أو إغلاق النافذة = «لا»** مثل صندوق النظام بالضبط، فلا تأكيد يحدث بالخطأ.
- **ضمان عدم الكسر:** أي عطل في بناء النافذة المثيمة يرجع تلقائياً لصندوق النظام الأصلي — الرسالة تظهر دائماً.
- الرسائل تتبع الثيم الحالي (فاتح/داكن) والأكسنت المختار من التخصيص، وتتوسط النافذة الرئيسية.

- `ui_theme.BUTTON_KINDS` / `button_style_for()` / `styled_button()` — هرمية الأزرار.
- `ui_theme._shade()` — تدرّج ألوان hover/pressed.
