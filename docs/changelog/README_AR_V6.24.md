# v6.24 — واجهة انتربرايز لصفحة الموبايل

## المشكلة
صفحة الموبايل كانت بتصميم بسيط قديم، بينما برنامج الكمبيوتر حصل على
تصميم Windows 11 Fluent العصري. المطلوب: صفحة ويب بنفس المستوى الاحترافي.

## الحل — إعادة تصميم كاملة للشكل، دون تغيير أي وظيفة
كل التعديل في CSS فقط: كل الـ IDs والـ classes والوظائف كما هي تماماً —
الفواتير، المسح بالكاميرا، طلب المسح من الكمبيوتر (v6.23)، الرمز PIN،
سجل الفواتير، والـ service worker كلها تعمل كما كانت.

### ما الذي تغيّر شكلياً
- **الهيدر**: تدرّج لوني أخضر داكن أنيق (نفس لون هيدر الكمبيوتر) مع
  أيقونة متدرجة، شارة اتصال على شكل كبسولة، وظل ثابت أعلى الصفحة.
- **شريط التنقل**: مقسّم (segmented) بأسلوب iOS/Fluent — التبويب النشط
  كبسولة بيضاء بارزة.
- **البطاقات**: طبقات بظلال ناعمة وحواف أدق (16px) مع خط فاصل بجانب كل عنوان.
- **الأزرار**: ظل خفيف، تأثير ضغط (يتصاغر لحظياً)، وحالات hover واضحة.
- **الحقول**: حواف أهدأ، وحلقة تركيز (focus ring) بلون التيل مثل الكمبيوتر.
- **الرسائل والتنبيهات**: شريط جانبي ملوّن + خلفية مموّهة — خطأ أحمر،
  نجاح أخضر، تحذير كهرماني، بنفس ألوان حالات الكمبيوتر.
- **الأرقام والأسعار**: أرقام جدولية (tabular) فلا تقفز الأعمدة.
- **الشريط السفلي**: زجاجي (blur) بظل أقوى، وزر الحفظ بارز.
- **الماسح**: إطار التصويب بلون التيل المضيء بدل الأخضر الفاقع.
- **إتاحة**: احترام prefers-reduced-motion، وحلقات focus-visible للأزرار.

## تقنياً
- `mobile.html`: استبدال كتلة `<style>` بالكامل بنظام متغيرات CSS موحّد
  (--pri #0D9488 مثل accent الكمبيوتر، الهيدر #0B3B39/#082B2A)، وتحديث
  theme-color إلى #0B3B39. لا تغيير في أي id أو class أو سطر JavaScript.
- `sw.js`: الكاش `pharmacy-mobile-v624` حتى تجلب الهواتف الصفحة الجديدة.
