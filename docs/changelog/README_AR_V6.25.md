# v6.25 — تقسيم أدكن لصفحة الموبايل

## الملاحظة
«مش كل حاجة ساحة على بعضها» — كل قسم كان بلوك عريض فوق اللي بعده،
والصفحة تطول بلا داعٍ.

## ما تغيّر (شكل فقط — لا وظيفة اتغيّرت)
- **العميل وطريقة الدفع جنب بعض** في سطر واحد بدل سطرين كاملين.
- **السلة وبطاقة العميل والدفع جنب بعض** على العرض الأوسع (تابلت/موبايل
  بالعرض أو الشاشات الكبيرة) بدل كرتين متراكبين.
- **إضافة دواء جديد**: الاسم إنجليزي/عربي جنب بعض، والمادة الفعالة/الشركة
  والشكل/التركيز في صفوف مزدوجة — الخطوات أقصر بكثير.
- **سجل الفواتير**: البحث والتاريخ في سطر واحد.
- **إيقاع أضيق عام**: حشو البطاقات والمسافات بينها وبين الحقول قلّت،
  فالصفحة أقصر وتقرأ أسرع.

كل الـ IDs والـ classes والـ JavaScript كما هي — التغيير تنسيق وتقسيم فقط.
`sw.js`: الكاش `pharmacy-mobile-v625`.
