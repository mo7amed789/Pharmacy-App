# Pharmacy Enterprise v6.11 — مزامنة سحابية مع Supabase

## الجديد
البرنامج بقى مربوط بقاعدة بيانات سحابية (Supabase) فيها كتالوج الأدوية
والكوزمتكس (55,240 صنف). التزامن على اتجاهين:

- **رفع تلقائي:** أي صنف بتضيفه أو تعدّله من شاشة الأصناف بيترفع للسحابة
  في الخلفية فوراً. لو النت مقطوع، البرنامج لا يتعطل ولا يبطّئ البيع —
  الخطأ بيتسجل ويظهر في الإعدادات، والعملية محفوظة محلياً كالعادة.
- **سحب يدوي:** من الإعدادات ← ☁️ المزامنة السحابية ← «سحب الكتالوج من
  السحابة»: ينزّل كل المنتجات ويحدّث الأسعار محلياً **بدون تكرار** (نفس
  منطق استيراد CSV: المطابقة على الاسم التجاري + التركيز).
- **رفع الكل:** زر «رفع كل الأصناف المحلية للسحابة» يرفع كتالوجك المحلي
  كله على دفعات، ويحافظ على نوع كل صنف (دواء / كوزمتكس).

## إيه اللي بيتزامن وإيه اللي لأ
السحابة تحفظ **بيانات الأصناف والأسعار فقط**. المخزون (التشغيلات
وتواريخ الانتهاء)، المبيعات، العملاء، والمستخدمون يفضلوا على جهازك —
جدول المنتجات السحابي مفيهوش مخزون.

## التفعيل (مرة واحدة)
1. انسخ الملف `supabase_config.example.json` إلى `supabase_config.json`
   جنب `main.py`.
2. افتح `supabase_config.json` واكتب فيه رابط المشروع والمفتاح
   (من لوحة Supabase ← Project Settings ← API Keys).
3. أعد تشغيل البرنامج. حالة المزامنة وآخر خطأ (لو فيه) بيظهروا في
   الإعدادات ← ☁️ المزامنة السحابية.

الملف `supabase_config.json` متجاهل في `.gitignore` — **المفتاح الحقيقي
لا يترفع على GitHub أبداً**. ممكن بدلاً من الملف تستخدم متغيري البيئة
`SUPABASE_URL` و`SUPABASE_KEY` (لهم الأولوية).

## الملفات الجديدة
- `supabase_client.py` — عميل PostgREST بالمكتبة القياسية فقط (urllib)،
  مفيش أي مكتبات جديدة.
- `cloud_sync.py` — التحويل بين الصيغتين + الرفع والسحب.
- `supabase_config.example.json` — قالب الإعداد.
- `tests/test_cloud_sync.py` — 5 اختبارات محلية بدون نت + اختبار حقيقي
  على الـ API بيشتغل لما متغيري البيئة موجودين (بيستخدم صف اختبار واضح
  الاسم وبيمسحه بعد نفسه).

## تعديلات على الملفات الموجودة
- `database.py`: بعد أي إضافة/تعديل صنف ناجح يتعمل رفع تلقائي في خيط
  منفصل باتصال قاعدة بيانات خاص (لا يوقف الواجهة ولا يتعارض مع SQLite).
  استيراد CSV **لا** يرفع صفاً صفاً — مفيش أي تغيير في سرعته أو سلوكه.
- `main.py`: قسم ☁️ المزامنة السحابية في تبويب الإعدادات (زر سحب، زر رفع
  الكل، وسطر حالة). لا تغيير في أي شاشة تانية.
- `.gitignore`: تجاهل `supabase_config.json`.
