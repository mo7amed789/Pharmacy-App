# v6.27: تحديث كتالوج العناية الشخصية

- 77 صنفاً إضافياً من قوائم شفاء المصرية، مع نوع الصنف بالعربية والاسم الأصلي والعبوة.
- تشمل شامبو وزيوت وصابون ومعجون وغسول فم وكريمات وجل ومزيل عرق وحلاقة وعناية بالطفل.
- الكتالوج السابق يحتوي أصلاً على آلاف منتجات العناية والقطرات. هذه إضافة وليست ادعاء بحصر كل منتجات السوق.
- بيع الزيت والصابون والمعجون ومزيل العرق والمناديل والحفاضات كعبوة كاملة فقط، بدون شريط أو حبة. أقراص وكبسولات الأدوية كما هي.
- الأسعار من المتجر وقت المراجعة، وليست أسعار شراء أو تسعيرة رسمية. راجع أسعار البيع قبل الاستخدام. المخزون يظل صفراً حتى تسجيل شراء فعلي.

بعد تحديث البرنامج، من الإعدادات اضغط «سحب الكتالوج من السحابة». ويمكن استيراد ملف catalog/personal_care_cosmetics.csv مباشرة بالطريقة المعتادة.

هذا التحديث مستقل عن وضع الاتصال السحابي التجريبي v6.26، ولا يفتح جدول فواتير للإنترنت ولا يغير الصلاحيات.
