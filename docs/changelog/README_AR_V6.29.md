# v6.29: تنبيه التحديث التلقائي

- يفحص برنامج الكمبيوتر GitHub بعد تسجيل الدخول بثلاث ثوانٍ، ثم كل ساعة ما دام مفتوحاً. الفحص لا يوقف البيع ولا يثبت شيئاً.
- يظهر تنبيه عربي عند اختلاف نسخة البرنامج عن آخر كود في فرع `main`، بخياري «تحميل وتثبيت الآن» و«لاحقاً: 24 ساعة».
- إغلاق التنبيه أو اختيار لاحقاً يؤجل تنبيه نفس التحديث 24 ساعة، حتى لو أغلقت البرنامج وفتحته. ظهور تحديث مختلف يسمح بتنبيه جديد. زر الفحص اليدوي يتجاوز التأجيل.
- لا يحدث التثبيت دون ضغط الزر ثم الموافقة على رسالة التأكيد، ومن حساب المدير فقط. احفظ أو امسح سلة البيع ومسودة المشتريات وأوقف سيرفر الموبايل أولاً.
- بعد التثبيت أعد تشغيل البرنامج. التثبيت يستخدم مسار النسخ الاحتياطي والرجوع الموجود؛ قاعدة البيانات والإعدادات والشهادات محفوظة.
- انقطاع الإنترنت لا يوقف العمل المحلي ولا يفتح رسائل خطأ تلقائية؛ يعاد الفحص في موعده التالي. الفحص اليدوي يعرض الخطأ.
- التحديث يتتبع commits في `main`، وليس قائمة إصدارات دلالية. عند تشغيل نسخة ZIP بلا سجل تثبيت معروف، يقول التنبيه إنه لا يستطيع تحديد النسخة الحالية، ويعرض تنزيل آخر كود باختيارك، ولا يدعي وجود نسخة أحدث مؤكدة.
- أصلح الفحص الأول الذي كان يعتبر آخر كود على الإنترنت مثبتاً بلا دليل، وأصلح مسح التحديث المكتشف عند فتح تبويب الإعدادات لأول مرة.
